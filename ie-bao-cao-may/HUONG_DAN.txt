IE BÁO CÁO MÁY v7.8 — CẬP NHẬT MACHINE DATABASE — HƯỚNG DẪN
=========================================================

NỘI DUNG
  IE_BaoCaoMay.html          Công cụ (một file, chạy không cần mạng, dùng Chrome hoặc Edge)
  PowerQuery\costing_query.pq          Query COSTING PROPOSAL cho MC Report
  PowerQuery\machinedb_latest_query.pq Không bắt buộc: đọc MACHINE DATABASE từ file lưu mới nhất
  Giao diện có hai ngôn ngữ: Tiếng Việt và English (nút ở góc trên bên phải).

------------------------------------------------
A. CÀI ĐẶT MỘT LẦN TRONG MC REPORT
------------------------------------------------
1. MACHINE DATABASE giữ nguyên là bảng Table1. Không đổi tên.
2. Data > Get Data > From Other Sources > Blank Query > Advanced Editor
   > dán nội dung costing_query.pq > sửa 4 dòng cài đặt (PlanFile, CostingFile, Server, Database)
   > Done > đổi tên query thành COSTING PROPOSAL
   > Close & Load To... > Table > New worksheet > đổi tên sheet thành COSTING PROPOSAL
3. Data > Get Data > Query Options > CURRENT WORKBOOK > Privacy
   > chọn "Ignore the Privacy Levels".
4. Lần làm mới đầu tiên:
   - Nhập tài khoản SQL: chọn Database, nhập tài khoản đọc dữ liệu (như macro costing).
   - Hộp thoại "Native database query": chọn Run.

------------------------------------------------
B. THỰC HIỆN HÀNG TUẦN
------------------------------------------------
1. MC Report: Data > Refresh All > Save.
2. Mở IE_BaoCaoMay.html bằng Chrome hoặc Edge.
3. Bước 1 - Dữ liệu đầu vào:
   - "Chọn file Excel...": chọn cùng lúc MC Report, Master plan và file đã lưu tuần trước.
     Công cụ tự nhận biết từng file.
   - "Chọn thư mục layout...": chọn thư mục gốc chứa layout. Chrome hỏi "Upload" thì chọn Upload
     (dữ liệu chỉ đọc trên máy, không gửi đi đâu).
4. Bước 2 - Bấm "Bắt đầu". Công cụ quét layout trước, mã hàng nào chưa có layout thì dùng costing.
5. Bước 3 - Duyệt và lưu:
   Cần duyệt          Mã hàng có dữ liệu mới hoặc khác database. Sắp xếp theo ngày vào chuyền.
                      Nhãn: Mới / Layout thay đổi / Costing -> Layout / Costing / Dữ liệu nhập tay.
                      Cột "Nguồn dữ liệu": chọn layout khác, costing, hoặc giữ dữ liệu hiện tại.
                      Cột "Máy": xanh = thêm, vàng = đổi số lượng (cũ -> mới), đỏ gạch = bỏ.
                      Đánh dấu ✓ từng dòng, hoặc "Duyệt tất cả mục đang hiển thị".
   Còn thiếu dữ liệu  Mã hàng trong kế hoạch chưa có layout, chưa có costing, chưa có trong database.
   Lỗi dữ liệu        Cần sửa tại nguồn. Dòng bị dán trùng trong database có thể đánh dấu để sửa.
   Không thay đổi     Layout trùng khớp database.
   Nhật ký quét       Kết quả từng file.
6. Bấm "Lưu MACHINE DATABASE" (thanh dưới cùng). File lưu tên MACHINE_DATABASE_yyyymmdd_hhmm.xlsx.
7. Đưa dữ liệu vào MC Report (chọn một cách):
   a) Dán sheet MACHINE DATABASE của file vừa lưu vào bảng Table1 (thay toàn bộ dòng); hoặc
   b) Khuyến nghị: lưu các file vào một thư mục cố định và dùng machinedb_latest_query.pq.
8. MC Report: Refresh All. Giữ file vừa lưu để tuần sau chọn làm "file đã lưu lần trước".

------------------------------------------------
C. QUY TẮC
------------------------------------------------
Thứ tự nguồn: Layout trước. Không có layout thì dùng Costing. Dữ liệu nhập tay (IETL, SMS, PDF, tt, E)
  chỉ được thay khi người duyệt chọn.
Mã hàng: đọc từ B3, D3, D4 (layout thường), B11 (Man-Machine), sau đó tên file.
  Mã ghép được tách: 3801.3802.3803 / 3801-3803 / 3901.04 / 00115_116_117 / xuống dòng.
  Mã khách hàng đặc biệt (SP..., S27..., F26..., DS...) giữ nguyên như khi ghi, không thêm hậu tố.
Biến thể 48HC / 16HC / ln: lấy từ chữ "48HC"/"16HC" trong layout, tên file, thư mục;
  nếu không có thì lấy theo kế hoạch (có ghi chú để kiểm tra).
Nhiều layout cho một mã: Bulk/Final > Initial, rồi OBD cao hơn, rồi file mới hơn.
Bỏ qua thư mục có tên Old layout, /old/, backup.
Quy tắc quét giống CheckMc (RunWeeklyIncrementalScan). File Man-Machine chỉ lấy Man-Machine-Ass/Prep.
Costing: hệ số 48 cho mã có hậu tố 48HC, còn lại 24.

------------------------------------------------
F. TRẠNG THÁI QUÉT, MÃ BĂM VÀ KIỂM TRA LẠI
------------------------------------------------
Nơi lưu (khi đã kết nối Layout Check):
  data\machinedb\scanstate.json      mã băm từng file layout (bản trước: scanstate.bak.json)
  data\validations\*.json            mỗi quyết định: người, thời điểm, file layout, sheet, danh sách máy
  Bản ghi do IE Báo cáo máy ghi có thêm: source = IE Báo cáo máy, layoutPath, layoutFp (dấu vân tay máy:số lượng).
  Không cần chọn "file đã lưu lần trước" nữa; file Excel đã lưu vẫn dùng được nếu chưa kết nối.
Hai loại mã băm của mỗi file layout:
  File Hash     SHA-256 của toàn bộ file. Giống lần trước -> bỏ qua, không đọc lại.
  Content Hash  SHA-256 chỉ của máy và số lượng (theo Prep / Ass / layout thường).
                Đổi định dạng, ghi chú, tên sheet, ô mã hàng -> KHÔNG tính là thay đổi.
Quyết định mới nhất có hiệu lực:
  1. Lấy bản ghi mới nhất của mã hàng (IE Báo cáo máy hoặc Layout Check).
  2. Đọc lại đúng file và sheet của bản ghi đó trong lần quét hiện tại.
  3. Máy trong file = máy trong bản ghi và database = bản ghi -> "Đã kiểm tra", không đề xuất.
     Nếu file IE Báo cáo máy chọn khác file IE đã xác nhận -> "Lỗi dữ liệu: File layout khác file IE đã kiểm tra".
  4. Máy trong file khác bản ghi -> file đã được sửa sau lần kiểm tra -> "Cần duyệt", IE kiểm tra lại.
  5. Bản ghi của IE Báo cáo máy nhưng database chưa có -> nhắc kiểm tra đã dán vào Table1 chưa.
Lần triển khai đầu: chọn thêm file CheckMc.xlsm cùng các file Excel khác. Cột "So với CheckMc" trong
  Nhật ký quét cho biết file nào khác lần quét CheckMc gần nhất. Từ lần sau không cần chọn CheckMc.

------------------------------------------------
G. LIÊN KẾT VỚI LAYOUT CHECK (V4)
------------------------------------------------
Mã hàng chỉ HOÀN TẤT khi Nhân viên IE lưu Đạt / Chấp nhận trong Layout Check.
1. Bước 1: bấm "Kết nối thư mục data của Layout Check...", chọn thư mục "data", Cho phép (xem và sửa). Nhập họ tên.
2. Khi quét, công cụ đọc kết quả của Layout Check:
   - IE đã Đạt / Chấp nhận, layout không đổi, CSDL đã khớp -> thẻ "Đã kiểm tra", không duyệt lại.
   - IE Không đạt, CSDL chưa khớp -> "Cần duyệt", nhãn "Theo Layout Check", nguồn mặc định là file IE đã dùng.
   - IE Tech xác nhận "Layout đúng — CSDL sai" -> như trên, kèm ghi chú của IE Tech.
   - IE Báo cáo máy yêu cầu sửa layout -> nhãn "Chờ sửa layout", giữ nguyên CSDL.
   - CSDL đã khớp sau lần Không đạt, hoặc IE Tech đã sửa layout -> ghi chú "chờ Nhân viên IE kiểm tra lại".
3. Khi lưu: mỗi mã hàng được duyệt từ layout (và mã "Không thay đổi" được đánh dấu "Ghi Đã duyệt") được ghi
   một ghi chú "Đã duyệt" vào data\approvals. Ghi chú này KHÔNG tính là kiểm tra; Layout Check chỉ hiển thị nhãn
   "IE Báo cáo máy đã duyệt", Nhân viên IE vẫn kiểm tra. Ghi chú trùng không được ghi lại.
   Các kết quả Đạt đã có trong data\validations giữ nguyên.
4. Đã duyệt nhưng CSDL chưa có -> nhắc kiểm tra đã dán vào Table1 chưa.

------------------------------------------------
H. BƯỚC 4 — PHÂN TÍCH THEO LOẠI MÁY VÀ CHUẨN BỊ
------------------------------------------------
Cần: MC Report có sheet MACHINE BY LINE, MC STATUS, PU LIST (công cụ tự đọc khi chọn MC Report).
1. Chọn khoảng thời gian (từ ngày, số tuần) và mức cộng chung (mặc định 10%).
2. Bảng xếp hạng nguy cơ thiếu: Máy có sẵn = cột "MC used for PDN" của MC STATUS (cộng theo nhóm máy),
   nhu cầu cao nhất = nhu cầu sản xuất theo ngày + mức cộng chung. Mặc định chỉ hiện nhóm có thể thiếu.
3. Đánh dấu loại máy cần xem, nhập tỷ lệ chuẩn bị % và số ngày. "Lưu tỷ lệ chuẩn bị" để dùng chung.
4. "Mở chi tiết": bảng ngang theo ngày cho từng loại máy (giống sheet chi tiết hiện tại):
   chuyền -> mã hàng: số máy sản xuất; dòng "chuẩn bị" màu vàng; chuẩn bị bị bỏ thì gạch ngang.
   Cuối bảng: Sản xuất, Chuẩn bị, Tổng sử dụng, Máy có sẵn, Còn lại (đỏ khi âm).
5. Quy tắc chuẩn bị: mã hàng mới vào chuyền (không chạy ở ngày làm việc trước) cần
   ROUNDUP(tỷ lệ x số máy mã đó) trong N ngày làm việc trước ngày vào chuyền (bỏ Chủ nhật).
   Không chuẩn bị khi hai mã cùng một file layout, hoặc nằm trong danh sách "Dùng chung layout".
   Ngày đầu tiên của kế hoạch không tính chuẩn bị (mã đang chạy).
6. "Gửi IE Tech duyệt chuẩn bị": IE Tech giữ / chỉnh / bỏ trong Layout Check (tab Chuẩn bị máy).
   Mở lại chi tiết để thấy số đã duyệt.
7. "Xuất Excel": mỗi loại máy một sheet có tô màu như sheet chi tiết hiện tại,
   sheet "PREP BY PU" đúng dạng TTL DEMAND BY PU (Combine.MACHINE | PU | ngày) để cộng vào báo cáo,
   sheet "CHƯA DUYỆT" liệt kê các dòng IE Tech chưa duyệt.

------------------------------------------------
K. BƯỚC 4: KẾ HOẠCH MỚI NHẤT VÀ CHI TIẾT MÁY CÓ SẴN (v5.3)
------------------------------------------------
1. Nhu cầu máy được tính trực tiếp: kế hoạch (MasterPlan-Full) × MACHINE DATABASE (dòng ngày mới nhất của mỗi
   mã hàng, cộng theo nhóm máy) — cùng cách tính với MACHINE BY LINE trong MC Report.
   - Dùng kế hoạch đã chọn ở tab Dữ liệu. Ngày vào chuyền thực tế khác kế hoạch: IE Tech chỉnh ở màn hình duyệt (mục L).
   - "Khác MC Report: n thay đổi trên m chuyền" -> "Xem thay đổi": chuyền, từ ngày - đến ngày, mã hàng cũ -> mã hàng mới.
   - "n mã hàng chưa có dữ liệu máy" -> "Xem mã thiếu": các mã hàng này chưa được tính nhu cầu máy.
2. Máy có sẵn = cột "MC used for PDN" của MC STATUS. Dưới dòng "Máy có sẵn" là chi tiết từng cột theo đúng công thức
   của MC STATUS: dấu + là máy nhận thêm (Machine in house, RENT, BORROW), dấu − là máy chuyển đi hoặc không dùng
   cho sản xuất (BROKEN, LENDING, TRA, PDC-Sample, Strapline, Line borrow, ATH transfer, PU3-Sample, PU2 keep).
   Nếu công thức trong MC STATUS thay đổi, công cụ tự đọc lại dấu theo công thức.
3. Chuyền có kế hoạch làm Chủ nhật: ngày Chủ nhật được hiển thị và tính sản xuất; ngày chuẩn bị vẫn bỏ Chủ nhật.
   Mỗi lần đổi mã hàng chỉ có một dòng chuẩn bị.

L. GIAO DIỆN THEO TAB (v6)
------------------------------------------------
Vai trò IE Báo cáo máy có 4 tab:
  Dữ liệu               Chọn MC Report, Master plan, file đã lưu lần trước, thư mục layout, thư mục data Layout Check, họ tên.
                        Có dấu ✓ khi đã nạp đủ.
  Cập nhật CSDL         Quét layout, duyệt, "Lưu MACHINE DATABASE" (thanh lưu chỉ hiện ở tab này). Số trên tab = mục cần duyệt.
  Thiếu máy & chuẩn bị  Xếp hạng nguy cơ thiếu, chi tiết theo ngày, gửi IE Tech, xuất Excel.
                        Không cần quét layout trước: cùng layout được nhận biết theo lần quét đã lưu.
  Báo sai lệch          Thông báo của IE Tech. Số trên tab = thông báo chưa xử lý.
Vai trò IE Tech chỉ có màn hình "Duyệt chuẩn bị".

IE Tech chỉnh ngày vào chuyền (xem mục M):
  Mở bảng bên phải của dòng chuẩn bị, nhập ngày vào chuyền thực tế.
  Ngày chuẩn bị tự lùi theo ngày mới (N ngày làm việc trước, bỏ Chủ nhật); thẻ hiển thị "vào chuyền 15/11 → 18/11".
  Dòng chưa duyệt được coi là "Giữ" khi chỉnh ngày; quyết định đã có (Chỉnh/Bỏ, số theo layout) được giữ nguyên.
  IE Báo cáo máy thấy ngày mới trong chi tiết theo ngày (nhãn "ngày do IE Tech chỉnh").

------------------------------------------------
M. MÀN HÌNH IE TECH (v6.1)
------------------------------------------------
1. Chọn vai trò IE Tech. Một lần đầu: "Kết nối thư mục data..." (thư mục data dùng chung) và
   "Kết nối thư mục layout..." (thư mục gốc chứa layout, để mở layout). Trình duyệt ghi nhớ hai thư mục này.
   Nhập họ tên, PU, chuyền phụ trách: gõ đầu mã chuyền, cách nhau bằng dấu phẩy
   (VD: "K" = tất cả chuyền K; "K,J" = chuyền K và J; "K05" = chuyền K05). Để trống = tất cả chuyền.
2. Bấm nút nhóm máy (số bên cạnh = dòng chờ duyệt) để chỉ xem nhóm máy đó. Bảng theo ngày giống sheet chi tiết của IE Báo cáo máy:
   chuyền -> mã hàng đang chạy theo ngày; dòng "↳ chuẩn bị" màu vàng; chuẩn bị đã bỏ thì gạch ngang.
   Cuối bảng: tổng theo từng PU (Sản xuất, Chuẩn bị, Tổng sử dụng), tổng toàn bộ, máy có sẵn (chi tiết MC STATUS), còn lại.
3. Trên mỗi dòng chuẩn bị:
   ✔ = giữ (một lần bấm)     ✖ = bỏ (một lần bấm, không cần lý do)     ✎ hoặc bấm vào dòng = mở bảng bên phải.
4. Bảng bên phải (chỉ nhập khi khác):
   - Số máy chuẩn bị.
   - SL theo layout: nếu khác CSDL, số chuẩn bị tự tính lại theo số này và IE Báo cáo máy tự nhận thông báo.
   - Ngày vào chuyền: ngày chuẩn bị tự lùi theo ngày mới.
   - "Lưu", "Bỏ chuẩn bị", "Cùng layout (bỏ và ghi nhớ)": lần sau cặp mã hàng này tự động không chuẩn bị.
   - "📄 Mở layout": xem các máy thuộc nhóm máy đang xem trong file layout ("Hiện tất cả máy" để xem toàn bộ)
   - "Tìm layout" (giống Layout Check): danh sách file của thư mục layout được ghi nhớ 8 giờ ("⟳ Quét lại" để cập nhật).
     Để trống ô tìm = gợi ý theo tên file: Đúng mã hàng > Mã hàng không có size > Cùng article. Gõ một phần tên file để tìm.
     Bấm vào file để xem bảng máy và tải file mở bằng Excel.
     và "Tải file để mở bằng Excel".
5. Bảng "Báo sai lệch tôi đã gửi" cho biết IE Báo cáo máy đã xử lý chưa.
   Mỗi dòng chuẩn bị ghi "vào chuyền dd/mm" để phân biệt khi một mã hàng vào chuyền nhiều lần.

------------------------------------------------
O. THAY ĐỔI v7
------------------------------------------------
IE Báo cáo máy
1. Ghi nhớ kết nối: chọn MC Report bằng nút "MC Report… (ghi nhớ)", thư mục layout bằng "Chọn thư mục layout… (ghi nhớ)",
   thư mục data Layout Check bằng nút kết nối, và họ tên. Lần sau bấm "🔁 Kết nối lại" (một lần bấm, trình duyệt có thể hỏi quyền).
   Mỗi tuần chỉ cần chọn kế hoạch mới bằng "Chọn file Excel…". Trạng thái quét lần trước lấy từ thư mục data, không cần chọn lại.
2. Tab Cập nhật CSDL: mỗi file layout là một lựa chọn, hiển thị ngày sửa file. Dưới lựa chọn là danh sách sheet có bảng máy
   (không gồm sheet ẩn và sheet F T S C), giống Layout Check: mặc định tích tất cả sheet Man-Machine, nếu không thì sheet đầu tiên
   ghi mã hàng đó (chữ đậm = sheet có ghi mã hàng). Tích thêm / bỏ tích để cộng các sheet; số máy và so sánh cập nhật ngay.
3. Tab Thiếu máy & chuẩn bị: thêm tổng theo từng PU (Sản xuất, Chuẩn bị, Tổng sử dụng) trong bảng và trong file Excel xuất.
   Dòng "IE Tech đã hoàn tất" cho biết ai đã hoàn tất, phạm vi nào, còn bao nhiêu dòng chưa duyệt.

IE Tech
4. Nút "✔ Hoàn tất duyệt": báo IE Báo cáo máy đã xong phạm vi đang xem (PU, chuyền phụ trách, tất cả nhóm máy).
   Nếu còn dòng chưa duyệt, hệ thống cảnh báo số dòng và số chuyền; vẫn có thể hoàn tất (các dòng đó giữ số đề xuất).
5. Quyết định được giữ sang tuần sau khi trình tự mã hàng trên chuyền không đổi (cùng chuyền, mã trước, mã sau, nhóm máy),
   kể cả khi ngày thay đổi (nhãn "ngày thay đổi"). Nếu số máy của mã sau trong CSDL thay đổi, dòng quay lại "Chờ duyệt".
   Một mã hàng vào chuyền hai lần với cùng mã trước: hai dòng đều hiển thị và dùng chung quyết định.
6. Xem layout: mỗi sheet một cột (layout chia nhỏ không bị cộng dồn), kèm ngày sửa file.

------------------------------------------------
P. IE TECH: CHỌN THƯ MỤC VÀ MỞ LAYOUT (v7.1)
------------------------------------------------
1. "Chọn thư mục data…" luôn mở hộp chọn thư mục (bắt đầu tại thư mục đã chọn lần trước); người dùng chủ động chọn.
   "🔁 Dùng lại: …" kết nối lại thư mục đã nhớ bằng một lần bấm.
   Sau khi kết nối, dòng trạng thái cho biết tên thư mục, số đề xuất, thời điểm và người gửi đề xuất mới nhất.
   Nếu thư mục chưa có đề xuất (prep\proposals), thông báo màu đỏ: hãy chọn đúng thư mục data mà IE Báo cáo máy dùng khi gửi.
2. Mở layout bằng Excel: nhập một lần "Đường dẫn mạng thư mục layout" (VD: \\server\IE\Layout hoặc Z:\Layout),
   là đường dẫn của chính thư mục đã chọn ở nút "Chọn thư mục layout…". Trong bảng xem layout:
   - "📂 Mở bằng Excel": mở file gốc trên mạng bằng Excel (trình duyệt có thể hỏi cho phép mở Excel).
   - "📋 Sao chép đường dẫn": dán vào Excel (File > Open) hoặc File Explorer.
   - "⬇ Tải bản sao": tải một bản sao về máy.

------------------------------------------------
Q. IE TECH: XEM BẢNG MÁY CỦA LAYOUT (v7.2)
------------------------------------------------
Trong bảng bên phải, "Tìm layout" -> bấm vào file: bảng máy hiển thị giống Layout Check.
- Danh sách sheet có bảng máy (không gồm sheet ẩn và F T S C), mỗi sheet ghi tổng số máy và số máy của nhóm đang xem.
  Mặc định tích như Layout Check: tất cả sheet Man-Machine; nếu không, sheet ghi mã hàng đó (chữ đậm); nếu không, sheet đầu tiên.
  Tích / bỏ tích để chọn sheet (VD: layout chia nhỏ).
- Bảng máy: mỗi sheet đã tích một cột và cột "Tổng đã chọn"; dòng thuộc nhóm đang xem được tô màu ("Hiện tất cả máy" để xem hết).
- Dòng so sánh: "<nhóm> theo sheet đã chọn: X máy · CSDL: Y". Nếu khác, bấm "Dùng X làm SL theo layout":
  ô SL theo layout được điền, số chuẩn bị tự tính lại; khi Lưu, IE Báo cáo máy nhận thông báo sai lệch.
- "Mở bằng Excel", "Sao chép đường dẫn", "Tải bản sao" vẫn có nếu cần xem file gốc.

------------------------------------------------
R. KHÔNG TÍNH CHỦ NHẬT; XUẤT EXCEL (v7.3)
------------------------------------------------
- Bảng theo ngày (IE Báo cáo máy và IE Tech), tổng theo PU, bảng xếp hạng nguy cơ thiếu và file Excel xuất: chỉ ngày làm việc,
  không có cột Chủ nhật. Sản xuất kế hoạch vào Chủ nhật (nếu có) không được tính trong các bảng này.
- Ngày chuẩn bị: N ngày làm việc trước ngày vào chuyền, bỏ Chủ nhật. VD: vào chuyền thứ Hai -> chuẩn bị thứ Năm, thứ Sáu, thứ Bảy.
- File Excel xuất: dòng chuẩn bị đã bỏ (IE Tech bỏ hoặc cùng layout) ghi 0 ở các ngày chuẩn bị, không gạch ngang,
  để khi cộng trong Excel không bị tính nhầm. Trên màn hình vẫn hiển thị số gạch ngang để dễ nhận biết.

S. ĐỔI NGÀY VÀO CHUYỀN VÀ SỐ NGÀY CHUẨN BỊ (v7.4)
------------------------------------------------
Trong bảng bên phải của IE Tech:
- Ngày vào chuyền: khi đổi, sản xuất trên chuyền thay đổi theo (cả bảng của IE Tech và IE Báo cáo máy):
  * Đổi SỚM hơn (VD 06/12 -> 03/12): mã hàng mới chạy đủ số máy từ 03/12, thay cho mã hàng trước trong các ngày 03/12 - 05/12.
  * Đổi MUỘN hơn: mã hàng trước tiếp tục chạy đến ngày trước ngày mới; mã hàng mới bắt đầu từ ngày mới.
  Ngày chuẩn bị lùi theo ngày mới. Tổng sản xuất, tổng theo PU và số máy còn lại tính lại theo ngày mới.
- Số ngày chuẩn bị (mặc định 3): chỉnh cho mã hàng cần chuẩn bị lâu hơn hoặc ngắn hơn. Ngày chuẩn bị là N ngày làm việc
  trước ngày vào chuyền, bỏ Chủ nhật. Nhãn "số ngày chuẩn bị do IE Tech chỉnh".
Cả hai thông tin được giữ cho các lần đề xuất sau (cùng chuyền, mã trước, mã sau, nhóm máy).

T. PU TÁCH (v7.5)
------------------------------------------------
Danh sách PU của IE Tech lấy từ dữ liệu (PU LIST của MC Report và đề xuất đã gửi), không còn cố định PU1 / PU2 / PU3.
Khi PU2 được tách thành PU2 SPORT và PU2 INTIMATE trong PU LIST, các PU mới xuất hiện trong ô "PU" của IE Tech.
Máy IE Tech chưa kết nối vẫn thấy danh sách PU đã dùng gần nhất trên máy đó.

------------------------------------------------
U. NÚT "CÙNG LAYOUT" (v7.6)
------------------------------------------------
Khi IE Tech bấm "Cùng layout (bỏ và ghi nhớ)" ở một loại máy của một dòng:
- Dòng đó được bỏ chuẩn bị.
- Cặp mã hàng (mã trước -> mã sau) được ghi nhớ trong thư mục data (prep\shared).
- Ngay trên màn hình IE Tech, các loại máy khác và các chuyền khác có cùng cặp mã hàng tự chuyển sang "Cùng layout — bỏ".
- IE Báo cáo máy bấm "Mở chi tiết" sẽ đọc lại danh sách mới nhất (không cần kết nối lại), nên mọi loại máy có cặp mã hàng này
  đều được bỏ chuẩn bị ở các lần tính sau.
- Ghi nhớ theo mã hàng (không theo chuyền hay loại máy). Mã trước gồm nhiều mã ("A + B") thì ghi nhớ từng cặp A -> mã sau, B -> mã sau.
- Muốn chuẩn bị lại cho một dòng cụ thể: IE Tech bấm Giữ / Chỉnh trên dòng đó (quyết định của IE Tech được ưu tiên).
