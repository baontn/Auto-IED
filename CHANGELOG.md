# Changelog

Dates are the build dates in the working sessions (Nov 2026). "LC" = Layout Check, "IBM" = IE Báo cáo máy (IE_BaoCaoMay.html).

## Layout Sim
- **v1.4** One operator for several machines: select them (Shift+click; the first clicked keeps the operator) and press 👤 / W; the others are marked as run by that operator (`by`), a short link is drawn when they are next to each other and a double-headed arrow with the walking distance when they are apart (2D and 3D); 👤 / W again splits them; side panel says who runs a machine and what an operator also runs; summary "N người chạy nhiều máy". OCR rebuilt around the boxes of the layout: boxes are found from their border lines, each box is copied to its own picture at a fixed text size (grey and black-and-white made inside the box) and read alone, a lost first digit is read again at two other sizes, columns come from the box centres; junk reads with very low confidence are not taken as numbers. Both sample pictures read 27/27 codes and numbers at 60 %, 80 %, 100 %, 150 % and 200 % zoom (3-4 s).
- **v1.3** Operators are set per machine, not per operation: "👤 Bấm máy để bật/tắt người" mode (2D and 3D: each click gives / removes that machine's operator; Esc to stop), "Tất cả có người"; the operation-number input was removed. Real models: a code now also lists the register models that can be set up as it (e.g. 1SLA ← Juki DDL-9000C, "đổi cài đặt"), not only models whose usual code it is, with "+N model khác, tổng M máy". Library is easier to find: header chip "📚 N mã · M model" (or "Chưa có thư viện máy", click to choose the file), library button inside the paste window when none is loaded, drop the Excel anywhere to load it; header detection accepts small variations of the column names.
- **v1.2** Line set-up in standard machine units: "Thiết lập chuyền theo số máy" (opens on first start) asks the number of standard machines (107 cm each), central table width (default 30 cm), start/end space and width (auto: table + machines, operator zones and aisles on both sides) and creates the central table; a pasted layout is then placed with its first row above and its second row below the table (backs against it), columns starting at the table's left end. Operators can be removed per station (one person runs two machines): checkbox in the side panel, 👤 button, key W, or by operation numbers ("36, 37" → Bỏ người / Có người); no seat/zone/aisle is drawn or checked there, the summary counts operators. Clicking a machine shows turn buttons next to it (⟲ ⟳ 180° 👤 🗑); side panel buttons kept. Operation numbers are big on the operator's seat (on the table when the station has no operator) and big in the 3D labels. OCR: doubtful reads (code not in the library, low-confidence or one-digit numbers) are read again, ties between equally close codes go to a code read elsewhere in the picture then to the most common in the register; both sample pictures read 27/27 codes and numbers. Export: fixed a duplicated SVG attribute that broke the PNG export.
- **v1.1** Paste a layout as a **picture**: Excel shapes copied (Ctrl+C on the shapes, Ctrl+V in Layout Sim), a screenshot, or an image file (drop / choose). Read with Tesseract OCR running in the browser (sidecar `layout-sim/ocr-engine.js`, ~8 MB, loaded only when needed, no network: the language data is answered inside the worker). Codes are corrected against the machine library (look-alike characters O/0, I/1/T, S/5/8, C/G/0...; a border read as an extra letter), cells expected but not read (column used in another row, or an operation number next to it) and missing operation numbers are read again one by one (grey picture and black-and-white, two crop widths), so cells with a grey fill are read too. The dialog shows the picture with coloured boxes (read / corrected / unknown / numbers / ignored) and the result as an editable tab-separated table before placing. On the sample picture (27 machines, 2 rows, grey cells): 27/27 codes and 27/27 numbers, about 3 s. Copied cells (text) still take priority over the picture.
- **v1.0** New offline tool `layout-sim/LayoutSim.html` (built from `src/layout-sim` by `tools/build_layout_sim.py`, SheetJS + three.js inlined, no network). Machine library read from the company Excel (sheet Machine_Needle: code, names, Dimension = length*width cm; machine register: name/brand/model) and cached in the browser. Paste a layout range from Excel (code rows + operation number rows; the number row side = operator side), machines placed to scale with an operator zone (chair, leg room) in front of each; drag (5 cm snap), rotate 90° / turn around 180°, rotate a block, align, pack, duplicate, undo/redo, input/QC tables, pillars, obstacles. Checks: machines overlapping, operator zone blocked, aisle behind the operator blocked, outside the line; ergonomic values editable. Flow line in operation order with distance. 3D view with simple models per machine family (lockstitch, overlock, flat bed / cylinder bed coverstitch, bartack, pattern sewer, bonding, ultrasonic, heat press, ironing, stretching, snap, suction, manual table), seated operators, labels. Library tab: sizes and 3D type per code (overrides), model -> code suggestions with "Confirmed" for IE Tech, Excel export/import. Save/open `.layout.json`, PNG export, print. VI/EN. Test `tests/layout-sim/smoke.py` (synthetic data, turnkey). Manual not written yet.

## IBM
- **v7.10** IE Tech: a prepare row skipped with "Cùng layout" is labelled "Cùng layout — bỏ" (in the IE Tech grid, the Consolidator detail and the Excel export) instead of "Đã bỏ"; the decision now also stores `sameLayout:true` (older ones are recognised by their reason). "Thiếu máy còn lại": click a PU row to show its lines and styles (with prepare rows) like the IE Tech panel, "Hiện tất cả mã hàng" for the whole group, and a per-group "Xuất Excel" button for the table (ExcelJS: formatted, frozen panes, red negatives, collapsible style rows, live formulas for PU totals, Total used, Left and Left after actions; checked by recalculating in LibreOffice). "Thiếu máy còn lại": the areas that hold machines (MC STATUS columns that are subtracted: lending, broken, TRA, sample room...) are listed under each table with their quantity, and the new action "Thu hồi từ khu vực" (take back, with instant preview, per area, quantity limited to what the area holds) adds those machines back for a date range. In the summary card the shortage by PU is now inside each machine group card (PU, machines used on the worst day, share, status); clicking a PU shows its lines, styles, per-day usage and actions; the separate "by PU" section is gone. "Trang chủ" button in the header. Every table can be resized by dragging the right edge of a column header (text wraps; double-click resets). The end date of the running style is set with a calendar dialog (Lưu / Theo kế hoạch / Hủy) instead of a browser prompt. Remembered connections: a new "Chọn file Excel… (ghi nhớ)" button remembers the plan, last-week and CheckMc files too; MC Report, Excel files, layout folder and data folder reconnect by themselves when the browser allows (otherwise the first click asks once); IE Tech / Supervisor share the same remembered folders. Test `tests/ie-bao-cao-may/ui_v710.py`.
- **v7.9 (added)** (1) After "Lưu MACHINE DATABASE" the shortage report counts the approved changes at once (label "gồm N thay đổi vừa duyệt"; the proposal records it and IE Tech sees a note). Horizontal tables like the IE Tech grid with chips for machine groups and PU, buttons "Chỉ ngày thiếu" / "Cả kế hoạch" (gaps between short periods stay), negative cells in light red with red text (also in the IE Tech grid).
