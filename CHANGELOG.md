# Changelog

Dates are the build dates in the working sessions (Nov 2026). "LC" = Layout Check, "IBM" = IE Báo cáo máy (IE_BaoCaoMay.html).

## Docs
- **Manuals** New illustrated HTML manuals for both tools (`manual/`), screenshots taken from synthetic demo data (`tools/manual_shots/`); Crystal logo on the home page. Old text guides, slide deck (v7.7) and the English guide removed.

## IBM
- **v7.10** "Thiếu máy còn lại": the areas that hold machines (MC STATUS columns that are subtracted: lending, broken, TRA, sample room...) are listed under each table with their quantity, and the new action "Thu hồi từ khu vực" (take back, with instant preview, per area, quantity limited to what the area holds) adds those machines back for a date range. In the summary card the shortage by PU is now inside each machine group card (PU, machines used on the worst day, share, status); clicking a PU shows its lines, styles, per-day usage and actions; the separate "by PU" section is gone. "Trang chủ" button in the header. Every table can be resized by dragging the right edge of a column header (text wraps; double-click resets). The end date of the running style is set with a calendar dialog (Lưu / Theo kế hoạch / Hủy) instead of a browser prompt. Remembered connections: a new "Chọn file Excel… (ghi nhớ)" button remembers the plan, last-week and CheckMc files too; MC Report, Excel files, layout folder and data folder reconnect by themselves when the browser allows (otherwise the first click asks once); IE Tech / Supervisor share the same remembered folders. Test `tests/ie-bao-cao-may/ui_v710.py`.
- **v7.9 (added)** (1) After "Lưu MACHINE DATABASE" the shortage report counts the approved changes at once (label "gồm N thay đổi vừa duyệt"; the proposal records it and IE Tech sees a note). (2) New tab "Thiếu máy còn lại" and a read-only **Giám sát** role: residual shortage per machine group after IE Tech's decisions (same numbers as the IE Tech grid), daily detail, who uses the machines on the worst day, **action log** recorded by the Consolidator in `data\prep\actions` (Thuê / Mua / Mượn / Dời kế hoạch / Khác; Dự kiến vs Đã chốt; also in the Nhật ký tab). Horizontal tables like the IE Tech grid with chips for machine groups and PU, buttons "Chỉ ngày thiếu" / "Cả kế hoạch" (gaps between short periods stay), negative cells in light red with red text (also in the IE Tech grid). Actions have a **real effect** (rent/buy/borrow add machines; Dời kế hoạch moves a style and the following ones on a line), with a live preview of the change, and a **summary card by machine group and PU** ("IE kiểm tra thêm" where nothing is done and it is still short; Excel export) once every action is confirmed. Each short machine group has its **own action panel under its table** with an instant result ("Xem thử" rows); the date move is in the same panel (choose a new loading date; moves the whole line); a date move already contained in a newer plan is marked "Đã vào kế hoạch" and not counted twice; redesigned summary card (KPI tiles, per group / per PU cards). The separate what-if card was removed (the Supervisor tries actions in the same panels).
- **v7.9** "Giữ dữ liệu hiện tại" in Cập nhật CSDL can now be confirmed (the ✓ box is no longer greyed out): button "Xác nhận giữ" (or tick + Lưu MACHINE DATABASE) moves the style to the new card "Đã xác nhận giữ"; it returns to "Cần duyệt" only when the layout content (machines/quantities) or the style's database data changes (the confirmation is then cleared), with a note who confirmed and when. "Hủy xác nhận" undoes it. Stored in `data\machinedb\keeps.json` (browser storage when the data folder is not connected).
- **v7.8** Grid of IE Tech keeps its scroll position after Keep/Remove/Save (was jumping to the top). IE Tech can edit the end date of the style running on a line; next style loads the next working day, prep days follow, applies to all machine groups; logged in Nhật ký (`prep/lineends`).
- **v7.7** "Chốt báo cáo" (per-PU check, warns but allows closing, flags changes after closing, `prep/closed`), Excel export gets STATUS sheet and `CHOT` file name; tab "Nhật ký" (by machine group and line, filters, Excel export); completion/notices refresh when the tab opens.
- **v7.6** "Cùng layout" remembered by style pair and applied at once to every machine group and line (IE Tech) and re-read by "Mở chi tiết".
- **v7.5** PU list of IE Tech comes from PU LIST / proposals (PU2 split into PU2 Sport / PU2 Intimate).
- **v7.4** IE Tech changing the loading date also moves production on the line; "Số ngày chuẩn bị" field.
- **v7.3** No Sunday columns anywhere; removed prep exported as 0 in Excel (no strikethrough).
- **v7.2** IE Tech layout viewer like Layout Check (sheet ticks, total of ticked sheets, "Dùng X làm SL theo layout").
- **v7.1** IE Tech always chooses the folders (reuse button), open layout in Excel via network path.
- **v7** Remembered connections (MC Report, layout folder, data folder), sheet ticks per layout file with file modified date, PU totals in grid, IE Tech "Hoàn tất duyệt", decisions carried to next week.
- **v6.x** Tabs (Dữ liệu / Cập nhật CSDL / Thiếu máy & chuẩn bị / Báo sai lệch), IE Tech by-day grid with machine group buttons and line filter, latest proposal per group, layout finder, `F T S C` sheets skipped.
- **v5.x** IE Tech module moved into IBM (LC stays rolled out unchanged), group-level comparison, Sunday fix for lines that work Sundays, demand computed from plan x MACHINE DATABASE, MC STATUS availability detail.
- **v4** Prep proposal (step 4), ratio per machine group (default BT1M 50 %).
