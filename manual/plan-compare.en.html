Plan Compare V1.0.0: User guideVI

Plan Compare

Compare the plan (TransformedMasterPlan) of several weeks to see how much the plan changed and how those changes raise or lower the demand of the machine types you pick. Runs in Chrome or Edge and sends no data anywhere.

1. How to use

  1. Pick the MC Report (the file with sheets MACHINE DATABASE, MACHINE GROUP, PU LIST, MC STATUS). The tool only reads it.
  2. Pick several TransformedMasterPlan files at once, one per week (sheet MasterPlan-Full). The plan date comes from the file name (for example 20261123) or the modified date; correct it in the "Plan versions" table if it is wrong.
  3. Set From date and Days to compare. Only days from this date are compared (days already run are not a plan change).
  4. Pick the machine types to watch (machine groups). The 3 most volatile groups are selected by default.

Every pair of consecutive versions is compared line by line and day by day: a different style is a change; machines per group come from the MACHINE DATABASE (rows with the latest date of the style).

2. Tabs

  • Overview: plan stability (% of line-days unchanged), lines changed per comparison, styles changed 2+ times, changes close to the run date; highlights; swing per machine group (Σ|Δ| machine-days, red when a day passes the threshold).
  • Machine demand by week: one chart per selected machine group, one line per plan version (newest is bold). The red band marks days where two consecutive versions differ by the threshold or more. The table gives peak, peak day, machine-days and the difference to the previous version.
  • Shortage: every plan version against the machines you have (column "MC used for PDN" of sheet MC STATUS). The table "Enough machines in the old plan, short in the new plan" lets you pick the pair of weeks: max shortage and days short of the old and the new version, labelled OK → Short / Shorter. Below it are the lines causing the shortage on the worst day (style before / after, Δ machines) and a table of the max shortage of each version. The charts of the demand tab show the "Available" line (red dashed) and a red area on the days the newest version is short.
  • Change list: each change (line, date range, style before / after), notice in days, and the Δ machine-days of every selected group. A red notice cell = changed too close to the run date. You can keep only the changes that touch the selected machines.
  • Change frequency: line × comparison table (days changed, darker = more) with "2/3" in red = changed in 2 of 3 comparisons, and the table of styles moved / added / dropped with start → end date in each version.

Export Excel writes 4 sheets: Changes, Group swing, Lines, Styles.

3. Notes

  • The plan file has no quantities, so "plan throughput" here means the line-days scheduled.
  • A style missing from the MACHINE DATABASE has zero machine demand (a warning shows in the versions table); its changes still count in the days changed.
  • Nothing is stored; reload the page and pick the files again.
