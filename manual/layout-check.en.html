Layout Check

Compare the machine list in the layout file with the Machine Database before a style loads on the line. Runs in Chrome or Edge and sends no data anywhere.

1. Introduction

Every style goes through a check loop with 4 roles:

RoleWhat to do
IE officerOpen the layout, compare with the database, save Pass, Accept with remark or Fail. Only an IE officer saving Pass completes a style.
ConsolidatorDecide whether a difference comes from the database or from the layout; fix the database.
IE TechFix the layout file when asked, or confirm that the layout is correct and the database is wrong.
SupervisorLoad the weekly plan, follow every step, handle styles that went over 2 rounds.
The pictures in this guide use synthetic demo data (styles DMO26-…, lines A, B, K, J, D, E), not company data. Screenshots show the Vietnamese screen; switch the tool to English with the EN button.

2. First-time setup on each computer

  1. Open LayoutCheck.html (or Open LayoutCheck.bat) with Microsoft Edge or Google Chrome. When using the intranet / GitHub Pages version: open the link given by the team.
  2. Type your Name (always type it the same way), choose your Role and PU.
  3. Click Choose… at Data folder, pick the shared data folder, click Allow.
  4. Click Choose… at Machine Database, pick the Machine Database file.
  5. (Optional) click Choose… at Layout folder, pick the shared folder where IEs save layouts (the big folder that contains all layouts).
  6. Click Start.
From the next time you only need to type your name (it is remembered) and click Start, then click Allow if the browser asks.

The list of PUs comes from the PU column of data\Linemapping.xlsx (columns Line, PU). When a PU is added or split, edit only this file; no software change is needed. The PU name must be written the same way on every row (for example PU2 SPORT); after editing, choose the data folder again or reopen the page.

3. Supervisor: load the weekly plan

  1. Log in as Supervisor.
  2. Click 📥 Load plan and choose the weekly plan file (sheet MasterPlan-Full, columns Line, Style No, Date).
  3. If a message says some lines have no PU: add them to data\Linemapping.xlsx, then click ⟳ Refresh.
  4. Follow the Status tab and the Activity log.

4. IE officer: check a style

4.1 Pick a style and a layout

  1. Log in as IE officer and choose the right PU. The left column To check lists the styles that load first this week on the PU's lines; the Urgent label = loads within the next 3 days.
  2. First time: click My lines in the left column, tick the lines you are in charge of, click Done. The choice is saved on this computer; Clear (show all lines) shows every line of the PU. The Search line box accepts several entries separated by commas or spaces: type J, K to show every line that starts with J or K; ✓ Tick all shown ticks only the lines currently shown.
  3. Switching tools: the All tools button at the top (and the two links "All tools" and "Open IE Báo cáo máy" on the login screen, also after logging out) takes you to the home page or to IE Báo cáo máy.
  4. Search style: every tab (Check, Variation log, Status, Activity log) has a style search box; type part of the name, case and dashes do not matter (for example 00202). It only filters what is shown; the counts on the tabs do not change.
  5. Click a style. In 1. Machine Database the machines of the database appear automatically ("Show machine list").
  6. In 2. Layout file the tool lists the files whose name contains the style: click Open on the right file (label "Same style"). If you do not see it: type part of the file name in the search box, click ⟳ Rescan (when you just saved a new file) or 📂 Browse….
  7. Check the sheets: sheets with a machine table are ticked automatically and the total of the chosen sheets is shown below. You can ＋ Add another file if the layout is split into several files.
The database refreshes itself (V4.3.2): when the Consolidator pastes a new database into the Machine Database file, Layout Check re-reads the file when you open a style, open a layout or come back to the window, and shows "The Machine Database file changed (…): it was reloaded". No need to click "Refresh" and no more false Fail from an old database. If the file is open or being saved in Excel, Layout Check keeps the old data, tells you once and tries again later.

4.2 Read the result and save

Layout Check compares by machine group (the database lists groups, the layout lists machine codes):

  • Matches by machine group: every group has the same total, even if the machine codes inside the group differ. You can save Pass. The differing machine codes are still listed for reference.
  • … machine group(s) differ: some group has a different total. Pass cannot be chosen. The result lists the differing groups and each machine code.
  • Machine codes that have no group in the database are compared code by code.
  • The warning "the machine list at the bottom of the layout differs from the operation table" (a big layout split into smaller layouts) is only a warning and does not block Pass.

In 4. Your decision:

ButtonUse whenComment
✅ PassLayout = database by machine groupComment is optional. The style is complete.
⚠ Accept with remarkThe differences are known; the Consolidator will align the databaseA comment is required.
❌ FailThe layout or the database must be correctedA comment is required (what must be fixed, who was informed).
A style that is Passed or Accepted disappears from the list. A Failed style stays until it is fixed and checked again. Every difference is sent to the Consolidator in the Variation log.

4.3 Layout that exists only as a PDF (manual check)

Use this when an old layout no longer has an Excel file, only a PDF.

  1. In step 2 click 📂 Browse… and choose the .pdf file (or pick the PDF in the suggestion list). The PDF appears in the right-hand column so you can read and type at the same time; View PDF here reopens the pane, "Open in new tab" opens the PDF in its own tab, the ✕ closes the pane.
  2. Enter the machine list: type the Machine code and Qty and click Add (or Enter in the Qty box; the machine code box suggests the codes found in the database). Or open Paste a machine list (copied from the PDF), paste lines of "machine code quantity" and click Read list. Total lines and headings are ignored. If the PDF is a scanned picture whose text cannot be copied, type it by hand.
  3. You must tick "I compared every line with the PDF file" before saving Pass or Accepted.

5. Consolidator: handle differences

Log in as Consolidator; the tab 🛠 Variation log shows the Failed styles. Every card shows: who found it, the IE's comment, the table of differing machines (DB at check, Layout, DB now, Still to fix) and which step the style is "Now with".

  1. Database is wrong (layout is right): fix the database in the IE Báo cáo máy tool (see the guide of that tool), or click 📋 Copy corrected machine list, open the Machine Database file, paste at the end of the Machine Database sheet, save and close the Excel file; then click ✅ Database updated — verify. When the database matches the layout (difference = 0) the style moves to the IE re-check step automatically.
  2. Layout is wrong: click ↩ Layout must be fixed and write what must be fixed. The style goes to IE Tech.
Always close the Machine Database file before clicking "verify". Do not rename or delete the folders inside data (activity, validations, variations).

6. IE Tech: fix the layout

Log in as IE Tech; the first tab becomes 🔧 Layouts to fix and shows only the styles of your PU for which a layout fix was requested. The top of the page shows the Consolidator's request and the machines in dispute.

There are two ways to answer:

  • ✔ Layout is correct — database is wrong (comment required): sends it back to the Consolidator to fix the database.
  • Fix the layout file in the shared folder, open the file again (click Remove on the old file, then 📂 Browse… or choose it from the list), then click ✔ I fixed the layout — check now. The system compares at once: when no difference is left the style goes to the IE officer for re-check; if differences remain, fix further or choose "Layout is correct — database is wrong".
When you open the new file, remember to remove the old layout file from the list; if both stay, the machines of the two files are added together and a large difference appears.

7. IE officer: re-check

A style that was fixed is at the top of the list with the label Fixed — waiting for IE re-check. The layout file of last time opens again by itself and the machines that were wrong are highlighted. Save Pass to complete; Fail returns to the Consolidator step (next round).

8. Follow-up: Status, Activity log

Styles over 2 rounds: the Supervisor talks to the parties; the Supervisor can perform the actions of the Consolidator and of IE Tech.

9. Rules to remember

  • Only an IE officer saving Pass/Accept completes a style. The IE Báo cáo máy tool only writes an "Approved" note (it does not count as a check).
  • The database uses only the rows with the latest date of each style.
  • A Pass already stored in data\validations is never rewritten.
  • A computer using an older Layout Check keeps working (it just does not show the newer labels).
  • Do not rename or delete the folders activity, validations, variations, approvals in data.
